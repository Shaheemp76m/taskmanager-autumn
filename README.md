# TaskFlow - Autumn Material UI 🍂

A basic, clean, and distraction-free Task Manager designed with **Google Material Design 3 (Material UI)** and styled with a cozy, warm **Autumn color palette**.

---

## 🎨 Autumn Color Palette & Material UI Design

- **Material Design 3 (M3) Standards**:
  - **Top App Bar** with integrated search and quick actions.
  - **Floating Action Button (FAB)** in the lower corner with smooth elevation.
  - **Elevated Cards** with rounded corners (16px) and subtle elevation shadows.
  - **Material Checkbox** with animated checkmark.
  - **Filter Chips & Tabs** for quick switching between `All`, `Active`, and `Completed` tasks.
  - **Outlined Dialog Modal** for adding/editing tasks.
  - **Material Snackbar** with an instant **UNDO** button.
- **Autumn Color Tokens**:
  - 🍁 **Terracotta / Burnt Sienna** (`#B84A28`) - Primary brand and FAB.
  - 🪵 **Maple Amber** (`#D97706`) - Highlights, active chips, and medium priority.
  - 🌾 **Chestnut Brown** (`#854D0E`) - Errands & warm earth tones.
  - ☕ **Olive Moss Green** (`#556B2F`) - Success checkmarks and low priority.
  - 📜 **Warm Linen / Parchment** (`#FDFBF7`) - Soft eye-friendly background.
  - 🌙 **Espresso Twilight Theme** - Dark theme with warm ember glow.

---

## ⚡ Core Capabilities

- **Instant Task Creation**: Add tasks directly from the top input by pressing <kbd>Enter</kbd> or click the **New Task FAB** (<kbd>N</kbd>).
- **Categories**: Preloaded with *Work & Projects*, *Personal & Life*, *Errands & Home*, and *Ideas & Learning*.
- **Real-Time Search**: Instant filtering by task title or description.
- **Sort Options**: Due date (soonest), priority, alphabetical, or recently added.
- **Undo Delete**: Snackbar notification allowing one-click task restoration.
- **Data Backup**: Export/Import JSON backups or load sample tasks anytime.
- **Audio Feedback**: Pleasant procedural Web Audio chimes (toggleable).

---

## ⌨️ Keyboard Shortcuts

| Key | Action |
|:---:|---|
| <kbd>N</kbd> | Open New Task Dialog |
| <kbd>/</kbd> | Focus Search Bar |
| <kbd>Esc</kbd> | Close Task Dialog |

## 🚀 How to Run

Open `index.html` directly in your browser:
```powershell
start index.html
```
Or via a local web server:
```powershell
npx serve .
```
